# Tulas International School Homepage Redesign

A modern responsive homepage redesign for Tulas International School.

## Tech Stack

- React
- Vite
- CSS
- Framer Motion
- Lucide React

## Features

- Responsive design
- Scroll-triggered animations
- Scroll progress indicator
- Custom cursor
- Animated cards
- Responsive navigation
- Campus and academics sections
- Sports section
- Testimonials
- Admissions CTA

## Run Locally

npm install
npm run dev

## Build

npm run build
